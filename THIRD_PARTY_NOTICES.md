Each user installs or connects these components separately and is responsible for complying with the current license and service terms that apply to their use.

## ElevenLabs

- ElevenLabs is an external text-to-speech API used for the English voice path in the template.
- This repository does not include an ElevenLabs API key, voice ID ownership, voice clone, SDK package, or audio generated from another user's account.
- Use your own account and a voice that you are authorized to use. Check the current [ElevenLabs API documentation](https://elevenlabs.io/docs/eleven-api/quickstart), plan limits, commercial terms, and voice permissions before publishing or monetizing a video.

## Python, FFmpeg, and Python packages

- Python and FFmpeg are installed separately by the user. FFmpeg builds can have different license configurations; consult the license notice that comes with the build you install.
- The setup scripts install packages such as Pillow and Requests into the user's virtual environment. PDF authoring/validation tools are also environment dependencies, not files redistributed by this repository.
- The template does not replace the upstream license notices for any dependency. Keep the notices supplied by each installed distribution and verify the exact versions used in your environment.

## Images, music, sound effects, and output videos

- `clock_check_3d.png` and the starter music/cue generated by `generate_starter_audio.py` are project assets intended for this template. Do not assume that an image, song, sound effect, stock clip, or voice found online is free to reuse.
- Public samples in `samples/` are generated from the included renderer and are provided to demonstrate layout. External reference videos are not redistributed by this repository.
- Before publishing a video, confirm the rights for every image, icon, music track, sound effect, voice, font, API output, and video clip used in that video. The rights for the final video are the combination of all those components.
